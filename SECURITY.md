# Security Policy

## Supported Versions

Security fixes are released for the latest minor release only.  
Earlier releases receive no security updates.

## Reporting a Vulnerability

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/logica-oss/synac/security/advisories/new).  
Do not open a public issue for a suspected vulnerability.

Include the affected version, reproduction steps, and the impact when known.  
Expect an initial response within 7 days.
